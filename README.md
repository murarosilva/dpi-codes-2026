# Digital Public Infrastructures: January 2026 Code

This repository contains the Jupyter notebooks used for the January 2026 Digital Public Infrastructures analysis.

## Notebooks

The notebooks are stored in `code/` and numbered in their intended workflow order:

1. Web mining
2. Reading PDFs
3. Data visualization
4. Extracting excerpts
5. BERTopic analysis
6. Automatic topic classification
8. Visualization of the reduced DPI topic model

## Data and outputs

Data sources, downloaded PDFs, generated datasets, and model files are intentionally excluded. Several are too large for a standard GitHub repository and may also have separate access or redistribution requirements.

File references are relative to the repository root. Create the referenced data and output directories locally, or adjust those paths for your environment, before running the notebooks.
